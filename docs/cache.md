# 本機快取與背景工作

## 資源與儲存邊界

快取僅處理兩個靜態主機：`prd-game-a-granbluefantasy.akamaized.net`、`prd-game-a-granbluefantasy-steam.akamaized.net`。`/assets/` 與 `/assets_en/` 分別存入 `ja`、`en` 分區，與介面語言獨立，不跨語言回退。完整 URL 的主機、路徑、版本與 query 均參與快取鍵。

動態 API、登入來源與其他透傳主機保持端到端 TLS。帶 Cookie／Authorization、Range 或使用者條件標頭的請求直接轉送；`private`、`no-store` 或帶 Set-Cookie 的回應不保存。HTTP 快取、重新驗證與失效語意適用於所有保存路徑。

| 資源 | 限制 |
| --- | --- |
| 磁碟容量 | 預設 5 GiB，可設定 1–100 GiB；兩語分區共用 LRU |
| RAM | 最多 2048 項／128 MiB，與等待保存的內容共用記憶體預算 |
| 單一物件 | 最多 16 MiB；超限內容串流轉送，不保存 |
| 快取下載 | 共用 16 個名額，磁碟與 RAM 命中不等待下載名額 |
| 瀏覽器連線 | 最多 256 個 |
| 背景落盤 | 含執行中最多 32 項／64 MiB，單一寫入工作者 |

## 命中、驗證與持久化

RAM 命中驗證有效期與 Vary，不等待磁碟、SQLite 或下載名額。RAM 未命中時取得同資源鎖並重新檢查快取，必要時才回源，避免並行重複下載。

完整下載通過內容驗證後，先回覆瀏覽器並使 RAM 可命中，再排入背景落盤。佇列滿載時跳過保存，不使瀏覽器等待磁碟；正常停止等待已接受的工作完成。每次替換使用獨立寫入代次，清理、刪除或較新替換使過期工作失效。

磁碟檔案使用原子替換，索引位於 `cache/index.sqlite3`。LRU 存取時間合併後每 5 秒批次更新，停止及容量淘汰前補存；異常退出可能遺失尚未補存的最近使用次序。

資源保存及回傳維持原始 body 與 Content-Encoding。內容驗證支援 gzip、zlib deflate、Brotli，解壓上限 64 MiB；檢查串流完整性、檔案前綴及 HTML 錯誤頁。SHA-256、檔案大小及內容檢查同樣適用於磁碟讀取、預熱與體檢。RAM 命中不重複解壓。

## 素材預取

預取只從瀏覽器已請求且符合快取規則的靜態 JS／JSON 中提取明確字串引用，包括常見 manifest。解析不執行 JavaScript，也不對預取結果遞迴發現資源。

引用只接受 HTTPS、同遊戲語言、既有主機／路徑／副檔名白名單，保留版本及 query。預取不攜帶瀏覽器 Cookie／Authorization、不跟隨重新導向、不重試，每筆網路工作最多 5 秒。

| 項目 | 上限或順序 |
| --- | --- |
| 發現佇列 | 32 份文件 |
| 單份文件 | 解碼後最多 1 MiB，最多 120 個有效 URL |
| 下載佇列 | 256 項 |
| 來源去重 | 4096 項 |
| 背景下載 | 同時最多 1 個，與前台共用總下載名額 |
| 優先順序 | JS／CSS／JSON，其次圖片及字型，最後音訊 |

佇列滿載丟棄額外工作，不阻塞瀏覽器。預取可能下載最終未使用的素材，實際效益取決於可用空檔與資源使用情境。

## 記憶體預熱

代理監聽就緒後，從最近七天的有效磁碟快取選取腳本、樣式、字型與小圖片，最多 512 項／32 MiB，單檔最多 1 MiB，仍受整體 RAM 上限約束。

預熱不回源、不更新磁碟 LRU、不增加請求、下載或命中數；已在 RAM、等待較新寫入或已替換的內容不被舊候選覆蓋。關閉預熱後保留已載入 RAM 的有效內容。

## 排程與生命週期

素材預取與記憶體預熱預設開啟。既有 schema 1 設定缺少對應欄位時使用此預設；明確保存的開關狀態持續保留。預取另外要求 HTTPS 快取已開啟且 CA 受信任，不會自動安裝或信任憑證。

前台素材回源進行中、完成後 500 ms，或透傳通道最近 500 ms 有資料活動時，暫停派發新背景工作。取得同資源鎖及下載名額後再次檢查前台狀態，延後工作保留在佇列中。已開始的下載可能繼續占用頻寬。

關閉開關、停止或退出會取消相應背景工作，不保存不完整下載。運行中修改快取偏好立即保存並更新工作狀態，不覆寫連線設定或代理 URL 草稿。隱藏視窗只暫停介面輪詢，背景代理及快取工作繼續運作。

## 快取體檢

體檢只能在代理停止後啟動，逐筆檢查索引、檔案大小、SHA-256 與內容格式，保留有效但已過期的日英文項目，移除損壞項目及程式擁有的孤兒／暫存檔。

修復會同步失效 RAM 及相關存取／寫入紀錄。不把未知中繼資料當成檔案路徑，也不跟隨連結刪除外部資料。介面顯示已檢查、已修復及失敗數；取消保留已完成的修復，並等待工作結束。

體檢期間禁止啟動代理、修改連線設定或清理快取；退出會取消並等待體檢。體檢與清理是不同操作，清理會刪除全部有效快取。

## 統計

預取請求不增加瀏覽器請求數或命中率分母；成功完整保存才增加下載總數及預取子計數。瀏覽器之後讀取預取完成的有效快取才計本機命中。304 不增加下載數或本機命中。

即時流量包含預取 body；記憶體預熱不增加流量或使用統計。介面只顯示下載總數，預取子計數保留於執行狀態。
