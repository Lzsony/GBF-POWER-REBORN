# 客戶端操作

## 平台與初始設定

0.1.0 支援 macOS arm64 與 Windows x64 程式碼建置。平台實測結果見[驗證紀錄](validation.md)。顯示名稱為 `GBF POWER REBORN`，系統識別為 `cc.lzsony.gbf-power-reborn`。

| 設定 | 初始值 |
| --- | --- |
| 連線模式 | 直連 |
| 監聽位址 | `127.0.0.1:8123` |
| 上游代理範例 | `http://127.0.0.1:7890` |
| HTTPS 快取 | 關閉 |
| 磁碟快取容量 | 5 GiB |
| 登入啟動 | 關閉 |
| 主題 | 跟隨系統 |
| 介面語言 | 依系統中文地區與 Hans／Hant 選擇；其他語言預設繁體 |

## 瀏覽器接入

啟動本機代理後，在瀏覽器代理插件（例如 SwitchyOmega／ZeroOmega）的 PAC 情境中填入 `http://127.0.0.1:8123/proxy.pac`，更新並套用。選單提供複製 PAC 位址。

PAC 依精確主機與網域後綴自動分流。匹配流量交由本機代理，其他流量直連；匹配規則沒有代理失敗後自動直連的備援。停止代理前應先將插件切回直連。程式不修改系統代理或插件設定；監聽埠變更後須更新插件 PAC URL。

直連模式由本機代理連往原始服務。上游代理模式接受 HTTP、SOCKS5 及 `socks5h` URL，支援帳密與 IPv6 位址；SOCKS 目的地主機名稱交由上游解析。

URL 右側的測試只確認上游 TCP 端口可達，不驗證帳密、協定或出口。測試成功後按「保存」才套用；未保存的修改不會改變目前運行路徑。

加速選項顯示但不可選取，0.1.0 不連接授權服務或遠端節點。

## 快取與憑證

HTTPS 靜態快取需要本機 CA：停止代理後，在憑證管理選單安裝並信任，再開啟本地快取。作業系統可能要求確認，瀏覽器可能需要重新啟動以載入信任。憑證狀態與快取開關在主頁同列顯示。

僅允許的靜態 CDN 進入 TLS 終止與快取流程；動態 API、登入來源及其他透傳主機保持端到端 TLS。快取拒絕不符規則的路徑、帶 Cookie／Authorization 的請求、Range，以及 `private`、`no-store` 或帶 Set-Cookie 的回應。

快取按 `/assets/` 與 `/assets_en/` 分為 `ja`／`en`，與介面語言無關。分區共用容量限制，保留完整 URL 作為鍵的一部分；沒有素材預取、記憶體預熱或手動體檢功能。

快取管理提供用量、容量上限與清理。容量範圍 1–100 GiB；容量、監聽埠、憑證操作與清理須停止後執行。清理只操作程式擁有的快取，不跟隨符號連結刪除外部資料。

## 設定與常駐

模式、HTTPS 快取、主題、語言及登入啟動變更即保存；代理 URL 須通過測試後明確保存。運行中切換失敗時回復原設定與路徑；回復失敗則停止並顯示錯誤，不重播遊戲請求。

關閉或最小化視窗會隱藏到選單列／系統匣，代理保持運作。隱藏時暫停介面輪詢，恢復後立即更新並重設流量取樣。使用選單「退出」或 macOS Cmd+Q 結束程式，停止時等待已接受的快取寫入完成。

## 統計口徑

| 指標 | 定義 |
| --- | --- |
| 線路延遲 | 預留給加速模式，0.1.0 固定顯示 `—` |
| 請求數 | 瀏覽器 HTTP 請求；未解密 CONNECT 每個隧道計一次，不包含 PAC 與背景探測 |
| 快取下載數 | 完整資源通過檢查並成功落盤的次數；304 不計入 |
| 本機快取命中率 | 無來源請求的本機命中數／符合快取條件的瀏覽器請求數；304 不算本機命中 |
| 即時流量 | 上下行轉送位元組差值；不包含 TCP/IP 開銷、背景探測或 loopback 快取回送 |
| JP／Steam 延遲 | 不使用本程式上游代理，直連公開頁 HEAD 的健康後續樣本中位數 |
| JP／Steam 超時率 | 有效窗口中超過 5 秒期限的完成探測／全部完成探測；DNS 或拒絕連線等非逾時錯誤不計入分子 |

公開頁每 10 秒取樣，窗口最多 20 次且不超過 200 秒；首次樣本不入中位數，最新失敗或 30 秒未更新時延遲顯示 `—`。系統 VPN／TUN 仍可能影響實際網路。這些數值不是遊戲內延遲或封包遺失率。

停止後重新啟動重設計數與時長；運行中切換保留本次計數，重建品質窗口。停止或首次取樣前不以零表示未知流量。

## 資料位置

| 平台 | 應用資料目錄 |
| --- | --- |
| macOS | `~/Library/Application Support/GBF Power Reborn` |
| Windows | `%LOCALAPPDATA%/GBF Power Reborn` |

目錄包含 `config.json`、`cache/`、`logs/` 與必要執行資料。設定格式為 `schemaVersion: 1`；格式錯誤時保留原檔並回報，不自動重設。上游密碼與 CA 私鑰使用作業系統秘密儲存，刪除資料目錄不等於移除憑證信任。
