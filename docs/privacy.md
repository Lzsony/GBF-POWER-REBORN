# 資料處理與隱私

本規格描述 0.4.0 的資料位置、用途與信任邊界。部署者的服務由部署者自行管理；通用版不連接 Control。

## 資料分類

| 資料 | 處理位置與用途 | 保存方式 |
| --- | --- | --- |
| 動態 HTTPS 內容 | 瀏覽器與原始服務；代理與 Gateway 轉發加密串流 | 不解密、不保存應用內容 |
| 靜態素材與中繼資料 | 客戶端快取、重新驗證及完整性檢查 | 本機磁碟／RAM；依容量淘汰，可手動清除 |
| 本機 CA 私鑰、上游密碼 | 客戶端 TLS 快取及代理認證 | Keychain／Credential Manager |
| 公開服務 profile | 客戶端判定 Control 入口與信任 | 建置時內嵌部署識別、HTTPS URL 與公開憑證 |
| 授權碼 | 客戶端向指定 Control 授權 | 作業系統秘密儲存，按部署隔離 |
| 裝置私鑰、host-key pin | 裝置簽名、SSH 認證與 Gateway 主機驗證 | 本機 `deployments/<deploymentId>/ssh/`；私鑰不送到 Control 或 Gateway |
| 帳號、裝置、節點與 grants | Control 管理本工具的存取權 | 獨立 SQLite；包含授權碼雜湊與加密副本 |
| Gateway 身份與 host key | 向 Control 簽名、提供 SSH 主機身份 | 在 Gateway 主機生成；私鑰不帶回管理機或分發 |
| 租約、連線與流量 | Gateway 授權連線，Control 管理狀態與用量 | 短期租約、去重裝置連線識別及每日上下行總量 |

客戶端設定、快取及日誌位於平台應用資料目錄 `GBF Power Reborn`。`config.json` 保存一般設定與按部署識別劃分的授權狀態，不保存上游密碼或明文授權碼。客戶端日誌每日輪替，保留最多七個日誌檔案。

不同部署不共用授權碼、裝置金鑰或受管理的 host-key pin。同一部署的 URL 或信任憑證改變時，已保存授權碼與 pin 失效，必須重新授權；一般代理及快取設定仍可使用。

## TLS 與連線資訊

動態 HTTPS 的 TLS 端點為瀏覽器與原始服務。轉發層不取得遊戲 Cookie、登入憑證或請求內容；本機代理、上游代理、Gateway 及網路供應者仍可能觀察各自鏈路的 IP、連接埠、時間、流量大小，以及協定暴露的主機名稱。

靜態 HTTPS 快取採本機 CA，本機代理可處理允許範圍內的靜態內容。動態遊戲與登入來源排除於 TLS 終止流程。CA 安裝與移除須由使用者操作；刪除應用資料不等於移除系統信任。

## 背景工作與遠端交換

素材預取只解析符合快取條件的靜態 JS／JSON 引用，下載同語言且符合白名單的素材，不執行腳本、不攜帶瀏覽器 Cookie／Authorization，也不解析動態 API。預取可能下載瀏覽器尚未請求或最終不會使用的素材，使用者可獨立關閉。記憶體預熱只讀取有效磁碟內容；體檢在本機完成，不上傳素材或檢查結果。

配置服務的客戶端向指定 Control 提交授權碼、裝置名稱、公鑰及簽名請求。授權後週期性檢查狀態，取得帳號可用節點、節點地址與公開 host key；這是本工具的授權資料，不包含遊戲帳號憑證。

Gateway 向 Control 提交節點健康狀態、目前連線的裝置識別、即時上下行速率與按 UTC 日期累計的流量，不上報遊戲請求或回應內容。租約有效期 45 秒，按 15 秒週期刷新；Gateway 約每 10 秒保存及上報計數。

## 服務資料與保存範圍

Control 與 Gateway 使用不同服務帳號、設定、資料及金鑰。同機部署不直接共用資料庫或資料目錄；Gateway 僅持有 Control 公開憑證，不持有 Control master key 或 TLS 私鑰。

Gateway 保留最近 UTC 日期窗口的日流量計數，最多涵蓋當日及前七個日期。Control 介面展示最近八筆日流量；Control 資料庫中的帳號、裝置、節點、稽核及歷史流量目前沒有自動刪除期限。部署者負責備份、存取權限與保存政策。短期 nonce 用於重播防護，到期後在後續請求時清理。

本機部署 journal 保存主機身份雜湊、管理 SSH 目標及撤回識別，屬於部署者的本機資料。公開建置輸出只有服務 profile 與公開憑證，不包含 journal、加入 ticket、私鑰、Control 資料庫或使用者授權碼。

## 診斷與責任

診斷使用錯誤類型、健康狀態及必要彙總資訊；一般日誌不保存完整 URL 查詢參數、Cookie、Authorization、請求／回應內容或秘密。公布診斷資料前仍須移除部署環境及帳號識別。

服務端或作業系統的日誌、備份及管理工具由部署者控制。第三方資源的權利歸屬見[免責與權利聲明](../DISCLAIMER.md)，存取與回報要求見[安全政策](../SECURITY.md)。
