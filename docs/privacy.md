# 資料處理與隱私

本規格描述資料處理範圍與信任邊界，實作狀態見[文件索引](README.md)。

## 資料分類

| 資料類型 | 處理位置 | 處理約束 |
| --- | --- | --- |
| 動態 HTTPS 內容 | 瀏覽器與原始服務 | 中間轉發層僅處理加密串流，不解密或保存應用內容 |
| 靜態素材與快取中繼資料 | 本機客戶端 | 僅保存符合快取條件的資源，支援容量管理與清除 |
| 本機 CA 與私鑰 | 本機客戶端 | 使用作業系統權限保護；私鑰不離開本機 |
| 代理設定、SSH 私鑰與授權碼 | 使用該配置的元件 | 與公開範例分離，不進入版本庫、一般日誌或交付包 |
| 專案帳號、裝置、節點與授權資料 | Control | 用於專案存取管理，不包含遊戲帳號憑證 |
| Gateway 執行資料 | Gateway | 限於服務執行所需，與 Control 儲存隔離 |

客戶端設定、快取及日誌保存在平台應用資料目錄下的 `GBF Power Reborn`；上游密碼及 CA 私鑰使用 Keychain／Credential Manager。快取依有效期及容量淘汰，可在停止後清除；設定保存至使用者修改或移除。日誌每日輪替並保留有限檔案。Control 與 Gateway 尚未實作，其資料欄位及保存期限仍待定義。

## TLS 與連線資訊

動態 HTTPS 的 TLS 端點為瀏覽器與原始服務。轉發層不取得遊戲 Cookie、登入憑證或請求內容；本機代理、上游代理、Gateway 及網路供應者仍可能觀察各自鏈路上的 IP、連接埠、時間、流量大小，以及協定暴露的主機名稱。

靜態 HTTPS 快取採本機 CA 方式，本機代理可處理允許範圍內的靜態明文內容及快取中繼資料。代理規則須排除動態遊戲與登入來源的 TLS 終止。CA 安裝須由使用者明確選擇，並提供移除信任及清理本機材料的流程。

## 背景快取處理

素材預取會在本機解析符合快取條件的靜態 JS／JSON 字串引用，只下載同語言且符合白名單的靜態資源，不執行腳本、不攜帶瀏覽器 Cookie／Authorization，也不解析動態 API。預取可能取得瀏覽器尚未請求或最終不會使用的素材，使用者可獨立關閉。

記憶體預熱只從既有磁碟快取載入有效內容，不產生網路請求。手動體檢在本機檢查索引與內容，刪除損壞或程式擁有的孤兒檔案，不上傳素材或檢查結果。

## 服務資料隔離

Control 與 Gateway 使用獨立服務與資料，即使部署於同一主機也不直接共用資料庫或資料目錄。服務間交換的授權及節點資訊，須在介面規格中列明用途與保存範圍。

部署者負責遠端主機的存取權、紀錄保存及資料清理。第三方資源的權利歸屬見[免責與權利聲明](../DISCLAIMER.md)。

## 診斷資料

診斷限於必要錯誤類型及彙總資訊，不保存完整 URL 查詢參數、Cookie、Authorization、請求／回應內容或秘密。

遙測、遠端回報或資料上傳能力須另行定義資料流、接收方、保存規則與使用者選擇，並同步更新本規格。
